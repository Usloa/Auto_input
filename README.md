# Auto_input

一个基于 Win32 API 的 Windows 自动输入工具，提供图形界面，可模拟键盘逐字输入，支持中英文混合文本。

## 功能特点

- 图形界面操作，适合直接粘贴和输入文本
- 支持中英文混合自动输入
- 可调节输入速度
- 支持开始、停止与进度显示
- 编译后可直接生成 `AutoInputTool.exe`

## 项目文件

- `main.c`：主程序源码
- `build.bat`：构建脚本
- `AutoInputTool.exe`：已编译好的可执行文件

## 编译方式

代码顶部给出的编译命令如下：

```bat
gcc -O2 -s -mwindows -municode -o AutoInputTool.exe main.c -luser32 -lkernel32 -lcomctl32 -lgdi32
```

如果已经配置好 MinGW 或其他可用的 GCC 环境，也可以直接运行：

```bat
build.bat
```

## 使用方法

1. 运行 `AutoInputTool.exe`
2. 在输入框中粘贴或输入需要自动键入的文本
3. 调整输入速度
4. 将光标切换到目标输入位置
5. 点击开始按钮执行自动输入
6. 如需中止，可点击停止按钮

## 适用场景

- 重复录入文本
- 演示自动输入效果
- 简单表单或文本框填充

## 注意事项

- 该工具通过模拟键盘输入工作，开始后请确保焦点位于正确的目标窗口
- 自动输入过程中尽量不要切换窗口或手动打断焦点
- 某些高权限窗口、远程桌面环境或受保护程序中，输入模拟效果可能受限制

## 平台说明

- 操作系统：Windows
- 界面技术：Win32 API
- 字体：默认使用 `Microsoft YaHei`
